Tokopedia Product Review Sentiment Analysis

This project presents an end-to-end Natural Language Processing (NLP) pipeline for sentiment analysis of product reviews collected from Tokopedia. The workflow covers the entire process, from automated data collection and text preprocessing to sentiment labeling, feature extraction, and machine learning classification.

The primary objective is to classify Indonesian product reviews into Positive, Neutral, or Negative sentiments using traditional NLP techniques and machine learning models.

Key Features

  • Automated review scraping from Tokopedia using Selenium.
  • Indonesian-specific text preprocessing and normalization.
  • Lexicon-based sentiment labeling.
  • Feature extraction using Bag of Words (BoW) and TF-IDF.
  • Sentiment classification using Logistic Regression and Multi-Layer Perceptron (MLP).
  • Performance evaluation using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

Data Collection

Customer reviews are automatically collected from Tokopedia product pages using Selenium and BeautifulSoup. The scraper navigates through multiple review pages, extracts review text and star ratings, and stores the collected data in CSV format for further analysis.

Text Preprocessing

The collected reviews undergo several preprocessing steps tailored for Indonesian-language text to improve data quality.

  • Lowercase conversion
  • URL, mention, hashtag, and punctuation removal
  • Number and special character removal
  • Duplicate and missing value removal
  • Indonesian stopword removal
  • Indonesian stemming
  • Slang word normalization
  • Tokenization
  • Additional English stopword removal

Sentiment Analysis

Sentiment labels are generated automatically using an Indonesian sentiment lexicon, eliminating the need for manual annotation.

  • Positive
  • Neutral
  • Negative

Feature Extraction

Two text vectorization techniques are implemented and compared.

  • Bag of Words (BoW) – Represents text based on word occurrence frequencies.
  • TF-IDF – Represents text by weighting words according to their importance within the dataset.

Machine Learning Models

Logistic Regression

A lightweight linear classifier commonly used as a strong baseline for text classification tasks.

Multi-Layer Perceptron (MLP)

A fully connected neural network consisting of multiple dense layers with ReLU activation and Dropout regularization, trained using the Adam optimizer and Sparse Categorical Crossentropy loss.

Both models are evaluated using 80:20 and 70:30 train-test splits.
