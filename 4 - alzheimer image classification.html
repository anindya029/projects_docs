Image Classification of Alzheimer's Disease using CNN

This project focuses on developing a deep learning model to classify Alzheimer's Disease stages from brain MRI images using a Convolutional Neural Network (CNN). The objective is to demonstrate how computer vision can assist in medical image analysis by automatically distinguishing between different stages of Alzheimer's Disease.

Project Overview

The model was developed using TensorFlow and Keras with a custom CNN architecture consisting of multiple convolutional and max-pooling layers to extract spatial features from MRI scans. Dropout regularization was applied throughout the network to reduce overfitting and improve generalization. The final classification layer uses a Softmax activation function to predict one of four Alzheimer's categories: Non Demented, Very Mild Demented, Mild Demented, and Moderate Demented.

The project began with data preparation, including organizing the dataset into training, validation, and testing subsets. Image preprocessing techniques such as resizing and normalization were applied before training the model. During training, model performance was monitored using accuracy and loss metrics to evaluate convergence and detect potential overfitting.

To assess the model's effectiveness, several evaluation techniques were employed, including accuracy and loss curves, a confusion matrix, and a classification report containing precision, recall, and F1-score for each class. These evaluation metrics provide a comprehensive understanding of the model's classification performance across all Alzheimer's stages.

This project highlights the complete deep learning workflow for medical image classification-from data preprocessing and CNN model development to evaluation and model export.
