Fall Detection Monitoring for Visually Impaired Individuals

An IoT-based fall detection and obstacle monitoring system for visually impaired individuals using ESP8266, MPU6050, and HC-SR04 sensors. The system performs real-time motion monitoring, obstacle detection, and remote data visualization through a web interface.

System Components
  • 1 x ESP8266
  • 1 x HC-SR04 (Ultrasonic Sensor)
  • 1 x MPU6050 (Inertial Measurement Unit)
  • 1 x Passive Buzzer

How does it work?

  • The MPU6050 sensor is used to read accelerometer and gyroscope data for orientation and motion monitoring. The system detects fall conditions by comparing acceleration and gyroscope values with predefined thresholds.
  • If a fall is detected, the system activates a police siren sound through the buzzer as an alert mechanism and sends a notification via Dweet.io.
  • The HC-SR04 ultrasonic sensor is used for obstacle detection. It continuously measures the distance to nearby objects and triggers an alert if an obstacle is detected within a certain range.
  • The ESP8266 sends sensor data to the Dweet.io cloud platform using HTTP GET requests. The transmitted data includes fall detection status, distance, acceleration, gyroscope values.
  • The website interface is developed using HTML, CSS, and JavaScript. JavaScript is used to fetch real-time sensor data from Dweet.io using the fetch API. The website dynamically updates sensor values, warnings, and system status information.

Problem I Encountered

During the development of the fall detection system, I encountered several challenges. One of the main issues was the sensitivity of the IMU sensor. Sometimes, it was not sensitive enough to detect falls, which I suspect was caused by incorrect accelerometer and gyroscope range settings that affect the sensitivity of the data.

Additionally, using a website as an alarm system for caregivers may not be the most effective solution because caregivers need to continuously monitor the website. It would be more practical and convenient if the alerts were sent through SNS notifications like WhatsApp or Telegram instead.
