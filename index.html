Developed an IoT-based fall detection and obstacle monitoring system for visually impaired individuals using ESP8266, MPU6050, and HC-SR04 sensors. The system performs real-time motion monitoring, obstacle detection, and remote data visualization through a web interface.

Image Classification of Alzheimer's Disease using CNN

This project focuses on developing a deep learning model to classify Alzheimer's Disease stages from brain MRI images using a Convolutional Neural Network (CNN). The objective is to demonstrate how computer vision can assist in medical image analysis by automatically distinguishing between different stages of Alzheimer's Disease.
