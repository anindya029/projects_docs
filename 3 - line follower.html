Line Follower with Fuzzy Logic

Developed an autonomous line-following robot using STM32 microcontroller programmed in C. Implemented fuzzy logic control to optimize servo motor response based on feedback from six infrared sensors.

System Components
  • 1 x STM32F103C8T6 (Blue Pill)
  • 6 x Infrared Sensors
  • 2 x Motor DC Gearbox
  • 1 x L298N Motor Driver
  • 2 x 18650 Batteries
  • 1 x Chassis

Project Overview

The robot moves by reading the position of the white track using six photodiode sensors placed at the front of the robot, divided into right1, right2, right3 and left1, left2, left3 sensors. When a sensor detects a black surface, it is interpreted as logic 1, while a white surface is interpreted as logic 0.

The sensor data is then used to calculate the error and derror values. Error represents the robot's position relative to the track, while derror represents the change in the previous error value. Both variables are used as inputs for the fuzzy control system. The fuzzy output is used to control the PWM of the right and left motor drivers, allowing each motor speed to be increased or decreased depending on the robot's position on the track.

The difference in speed between the right and left motors affects the robot's turning direction. For example, if the right motor rotates slower while the left motor rotates faster, the robot will turn right, and vice versa. The robot is able to continuously follow the track because the system constantly performs direction correction based on sensor readings and fuzzy calculation results.
